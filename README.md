# The Cosmere Archives — APK Downloads

This public repository is dedicated to downloadable Android APK builds. Application source code is kept separately in a private repository.

When public publishing is enabled, new pre-release APKs will appear under [Releases](https://github.com/cosmerearchives-creator/Mind-map-releases/releases). Download the `The-Cosmere-Archives-debug.apk` asset directly.

**Important:** These are early test builds. Consistent release signing and in-app update installation have not yet been configured. Back up books and research before changing versions.

To enable automatic publishing, the private source repository must have an Actions secret named `PUBLIC_RELEASES_TOKEN`: a fine-grained GitHub token with **Contents: Read and write** access to **this public repository only**. Never put this token in an APK or commit it to GitHub.
